06 — TIME COMPLEXITY

How much work?

Time Complexity ante clock seconds kaadu. Input size tho algorithm work ela grow avutundo.

FIRST IDEA

N means what?

DSA problems lo N ante usually input size — enni items unnayo.

👦 👧 👦 👧 👦

5 students unte N = 5.

100 students unte N = 100.

1,000 students unte N = 1,000.

N = input size Bigger N → usually more work
01

O(1) — Constant

Input size entha unna, required operation number almost same ga untundi.

arr[0]
Real life:

Mee shelf lo first book ni direct ga access cheyyadam.

Books 5 unna, 100 unna, first position ni direct ga access chesthe one direct operation laga think cheyyachu.

O(1)
02

O(N) — Linear

Usually one by one every item ni process chesthe O(N) type behavior vastundi.

for (let i = 0; i < n; i++) {
  console.log(arr[i]);
}
Real life:

Teacher every student attendance check chestunnaru.

10 students → around 10 checks.
100 students → around 100 checks.

O(N)
03

O(N²) — Quadratic

Oka N loop inside another N loop run ayithe often N × N work vastundi.

for (let i = 0; i < n; i++) {
  for (let j = 0; j < n; j++) {
    work();
  }
}
Real life:

Classroom lo every student ni every other student tho compare cheyyali anuko.

Students perigina koddi comparisons very fast ga increase avutayi.

O(N²)
04

O(log N) — Logarithmic

Every step lo search space ni roughly half chesthe logarithmic behavior vastundi.

Real life:

Dictionary lo oka word find cheyyali.

First page 1 nunchi one-by-one search cheyyakunda, middle daggara open chestham.

Word earlier unte left side, later unte right side.

Ila search area repeatedly half chestham.

O(log N)
05

O(N log N)

N work and log N type splitting together vachinappudu ee complexity commonly kanipistundi.

Common example:

Merge Sort laanti efficient sorting algorithms.

O(N log N)
06

O(2ⁿ) — Exponential

N perigina koddi possible choices very fast ga increase avutayi.

Simple idea:

Every item ki 2 choices unnayi: choose / don't choose.

N items ki possible combinations 2ⁿ varaku grow avvachu.

O(2ⁿ)

REMEMBER THIS

Common Time Complexities

O(1)

Constant — almost same amount of work

O(log N)

Search space repeatedly reduces

O(N)

Usually one full pass

O(N log N)

Common in efficient sorting

O(N²)

Often nested loops

O(2ⁿ)

Many combinations / choices

07 — BIG O

What does O(...) mean?

Big O is a notation used to describe how an algorithm grows as input grows.

O(N)

Don't be scared by the notation.

O(N) ante "N exactly seconds" ani kaadu.

It means the amount of work roughly grows with the input size N.

EXAMPLE

N = 5

O(N) algorithm roughly 5 items process cheyyachu.

NOW

N = 1,000

Same type of algorithm roughly 1,000 items process cheyyachu.

One key idea:

Big O exact operation count ni focus cheyyakunda growth ni focus chestundi.

08 — SKILL

How to find Time Complexity?

Code chusi complexity identify cheyyadaniki beginner-friendly rules.

01

One loop → Usually O(N)

for (let i = 0; i < n; i++) {
  console.log(i);
}

Loop N times run avutundi.

02

Two separate loops → O(N + N) → O(N)

for (...) {
  work();
}

for (...) {
  work();
}

N + N = 2N. Constant 2 ni ignore chesthe → O(N).

03

Nested loops → Usually O(N²)

for (...) {
  for (...) {
    work();
  }
}

Outer loop N times. Inner loop each time N times. So N × N = N².

04

Ignore constants

3N → O(N)
100N → O(N)
2N + 5 → O(N)

Big O lo growth important. Fixed constants usually ignore chestham.

05

Keep the biggest growing term

N² + N + 10

Large N daggara N² fastest ga grow avutundi. So complexity → O(N²).

09 — SPACE COMPLEXITY

How much memory?

Time tells us about work. Space tells us about additional memory.

💾

Think about your study table.

Table meeda books, notebooks, pens pettukuntam.

More items store cheyyadaniki more space kavali.

Space Complexity = Algorithm use chese additional memory ela grow avutundi?
01

O(1) Space

Input size perigina kuda extra variables count same ga unte constant extra space.

let sum = 0;
let count = 0;

Ikkada few variables matrame extra ga use chestunnam.

02

O(N) Space

Input size perigina koddi manam create/store chese extra data kuda perigite O(N) type space vastundi.

let newArray = [];

for (let i = 0; i < n; i++) {
  newArray.push(arr[i]);
}

N items ni additional array lo store chestunnam.

Important:

Input already ichina memory and algorithm create/use chese additional memory ni carefully distinguish cheyyali.
